# Madden-26-Roster-Size-Increase

This mod increase follow Values

Roster size Preseason to 80
Roster Cutday/ regular Season to 65
Pactice Squad to 3 Years

for gamebalance was needed to increase salary cap curves. For start +40mil, then soft curve up to 450 over 10 years.

Attention!!
To use the new values you NEED to start NEW Franchise Game !! its not possible to get the values on exiting save games!

The tableoverviews for  rosters are limited by EA hardcoded in exe file to 60, only in line up can you see all players on one table / overview. in depth table can you see seperatly each positions.

The minimum rostersize is hardcoded by EA in exe file . for better balance you should choice highest value.
the AI Teams going in simulations switching between 60-65 roster size

German
Dieser Mod erhöht die folgenden Werte:

Kadergröße in der Vorsaison auf 80
Kadergröße am Cutday/in der regulären Saison auf 65
Trainingskader nun bis 3 Jahre 

Aus Gründen der Spielbalance war es notwendig, die Team-Gehaltsobergrenzen anzuheben. Zu Beginn +40 Mio., dann eine sanfte Kurve bis auf 450 über 10 Jahre.

Achtung!!
Um die neuen Werte zu nutzen, MUSST du ein NEUES Franchise-Spiel starten!! Es ist nicht möglich, die Werte in bestehende Spielständen zu übernehmen!

Die Tabellenübersichten für die Kader sind von EA in der EXE-Datei fest auf 60 begrenzt; nur in der Lineup/Aufstellung kannst du alle Spieler in einer Tabelle/Übersicht sehen. In der Detailtabelle kannst du die einzelnen Positionen separat einsehen aber nicht das komplette Roster in einer Gesamtansicht.

Die minimale Kadergröße ist von EA in der EXE-Datei fest codiert. Für eine bessere Balance solltest du den höchsten verfügbaren Wert auswählen.
Die KI-Teams wechseln in Simulationen zwischen einer Kadergröße von 60 und 65 Spielern über die Jahre.
